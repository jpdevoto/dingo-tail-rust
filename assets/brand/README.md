# DingoTail branding

The original user-supplied DINGO reference files are not included in this export.
New artwork was produced with the built-in image tool using those originals as
references. Exact final generation/edit prompts are in provenance/ and embedded
in PNG metadata. The mascot refinement derives from the first generated circular
mascot; the wordmark cleanup derives from the first DINGOTail extension. The
lockup combines those approved designs into a horizontal illustration.

- mascot-master.png: full-resolution circular tail-chasing mascot.
- mascot.png: normalized 512px transparent application artwork.
- wordmark-master.png / wordmark.png: full-resolution and compact wordmark.
- lockup.png: mascot with wordmark.
- icon-{16,24,32,48,64,128,256}.png: raster icon sizes.
- dingotail.ico: Windows icon containing all seven sizes.

The ready-to-embed PNG and ICO resources are included. Development-only artwork regeneration tooling is excluded from this export.
